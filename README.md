# Lesson 03: Drawing in Game Lab

IST Unit 03 practice lab for Fitzgerald High School College and Career Academy.

## Activities
- Identify: six vocabulary matches.
- Build: two drag-and-drop drawing-code puzzles.
- Apply: four code prediction questions.
- Debug: three code corrections.

15 scored items, converted to a percentage. A perfect first check completes each activity; otherwise students have one additional check. Questions, choices, and code tiles are shuffled per attempt, with browser progress recovery. Reset requires a confirmed grade-submission receipt.
